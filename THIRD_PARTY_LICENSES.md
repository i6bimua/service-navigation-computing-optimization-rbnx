# Third-Party Components

RoboNix Navigation Computing Optimization keeps heavyweight third-party projects and checkpoints outside this
repository. Users should install and cite them according to their own licenses.

| Component | Use | Distribution policy |
| --- | --- | --- |
| InternNav | VLN evaluator/model integration | External dependency or source checkout |
| InternVLA-N1 / DualVLN checkpoints | S1/S2 model weights | External download only |
| Habitat / Habitat-Sim | R2R-CE simulation | External dependency and dataset setup |
| RoboNix | Robot skill registry and orchestration | External integration target |
| Diffusion Policy | S1 trajectory generation dependency in InternNav | External dependency |
| websockets | Optional cloud-edge transport | Python package dependency |
